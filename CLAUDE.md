# Инструкции для Claude Code

Правила проекта находятся в общем файле:

@AGENTS.md

## Коммиты

- Не отмечать Claude, Anthropic или любую другую модель/ИИ-агента автором или соавтором коммитов.
- Не добавлять подписи `Co-Authored-By` от имени ИИ, `Generated with Claude`, `Claude-Session` или ссылки на сеанс ИИ в коммиты и описания pull request.
- Использовать настроенные имя и email владельца Git. Не менять их на данные агента.
- Перед push проверять автора, коммитера и полный текст каждого нового коммита.
- Делать коммит и push только по явной просьбе пользователя.

Автоматические подписи Claude Code отключены в `.claude/settings.json`.
