        Настройка Google Cloud

        Нужна однократная настройка проекта Google Cloud. Инструкция Google. Секрет клиента вводить не нужно.

        1. Включите Google Drive API и Google Picker API в одном проекте Google Cloud.
        2. Создайте OAuth-клиент типа «Веб-приложение». Разрешённый JavaScript origin: . Добавьте свой аккаунт в тестовые пользователи, если проект в режиме Testing.
        3. Разрешение для выбранного файла: https://www.googleapis.com/auth/drive.file.
        4. Создайте браузерный API key для Drive и Picker. Разрешите сайт приложения и https://docs.google.com/*.
        5. Введите Client ID, API key и числовой Project number ниже.
